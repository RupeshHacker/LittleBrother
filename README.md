## 🛠 Features

### 🔍 Lookup Modules
* **Identity:** Last name, First name, and Surname lookups.
* **Communication:** Reverse phone & Email lookups.
* **Location:** Address lookup, IP locator, and BSSID locator.
* **Social Media:** Twitter, Instagram, Facebook, and LinkedIn Employee search.
* **Technical:** Mail IP tracker, EXIF data reader, and Google Dorking.

### 🗃 Profiler System
* **Profile Management:** Create and manage target profiles.
* **Database:** Structured local storage for gathered intel.

### ⚡ Other Tools
* **Hash Tools:** Reverse hash lookups and Bruteforce modules.

## 📥 Installation

### Linux / MacOS
Ensure you have `git` and `python3` installed:

```bash
# 1. Clone the repository
git clone [https://github.com/RupeshHacker/LittleBrother](https://github.com/RupeshHacker/LittleBrother)

# 2. Enter the directory
cd LittleBrother

# 3. Install requirements
python3 -m pip install -r requirements.txt
